# Form & Function

## Project Overview

Form & Function is a responsive interior design website created for DIG 2500. The website helps users explore how interior design choices affect both the appearance and functionality of different spaces. Users can browse four room types, compare before-and-after transformations, experiment with different design styles, and learn fundamental interior design principles.

## Features

- Responsive layout for desktop and mobile devices
- Interactive room selector
- Room style changer (Modern, Minimalist, Coastal, Contemporary)
- Before-and-after room transformation
- Interior design principles section
- Sticky navigation
- Back to Top button
- JavaScript interactions for updating room content and image changes

## Technologies Used

- HTML5
- CSS3
- JavaScript
